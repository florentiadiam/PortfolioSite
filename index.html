Thesis project (completed, 2026), Interactive Game Agent: An AI Companion with adaptive Personality and Behavior

NEXUS-7 is a first-person stealth horror game developed in Unity, set in the abandoned laboratory of Helix Dynamics, also known as NEXUS-7. The player infiltrates the facility to extract classified data from "Project Chimera", a secret genetic modification program that transformed human subjects into mutated creatures known as Crawlers. Throughout the mission, the player is assisted by AXIOM, an AI companion that provides real-time tactical guidance, hacks security systems, and warns of incoming threats. The game features a hybrid AI architecture combining Utility AI and a fine-tuned Large Language Model. The Utility AI, implemented in C#, evaluates the current game state: guard proximity, alert level, available hacks, and time remaining and assigns scores to possible actions to determine the optimal response. The LLM component is built on Microsoft's Phi-3 Mini, fine-tuned using LoRA on a custom dataset of 200 dialogue examples designed specifically for the game's environment. The model runs locally via a Python Flask server and communicates with Unity through HTTP requests, generating natural language responses in real time. For efficient inference, the model was converted to GGUF format and runs through llama.cpp, achieving response times of 2-3 seconds on consumer hardware.
